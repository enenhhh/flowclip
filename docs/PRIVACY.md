# 隐私与数据处理

本文说明 FlowClip 1.4.0 源码当前如何读取、传输和保存数据。它是面向用户和审查者的技术说明，不替代部署者所在地区可能要求的法律文件。

## 核心原则

- FlowClip 没有官方云账号、遥测、广告、分析 SDK 或远程崩溃上报。
- 运行时只连接用户填写的服务器 URL。
- 内置服务器只在内存中保存最新一条剪贴板内容，不保存历史数据库。
- 用户主动传输的普通文件独立于剪贴板内容，会持久保存到服务器和下载设备的本地存储，直到用户删除。
- FlowClip 不提供 TLS 或端到端加密；链路保护取决于局域网、HTTPS 隧道或加密虚拟网络。
- 配置会保存在本机，其中包含共享密钥。
- Android 收到的图片会保存成文件，生命周期不同于内存中的服务器内容。
- 桌面端和 Android 都可以运行内置 HTTP 服务器。

## 数据流

### 桌面自动同步

Windows、Linux 和 macOS 开启“自动同步剪贴板”后，FlowClip 在应用运行期间轮询系统剪贴板变化。检测到支持的文本或图片后：

1. 文本编码为 UTF-8；图片解码并规范化为 PNG。
2. 客户端计算内容 SHA-256，并把原始内容 Base64 编码到协议 JSON 中。
3. 请求携带设备 ID、内容 ID、类型、MIME、可选文件名、时间戳和共享密钥鉴权头。
4. 服务器替换内存中的上一条内容。
5. 其他客户端轮询后把内容写入本机剪贴板，Android 图片除外。

关闭自动同步后，只有用户点击发送/接收才触发相应操作。

FlowClip 只处理它支持的最新一条文本或图片。其他自定义剪贴板格式、富文本、文件列表本身和完整剪贴板历史不会上传；Windows 从文件列表识别到图片文件时，可能读取其中首个有效图片的内容进行同步。

### Android

Android 不在后台读取或自动发送系统剪贴板。发送发生在以下情况：

- FlowClip 位于前台，用户点击“发送当前剪贴板”；
- 用户从其他应用拖入内容，或通过系统分享菜单把单项/多项文本、图片或文件发送到 FlowClip。

后台前台服务只轮询服务器并接收。收到文本时写入系统剪贴板；收到图片时保存到本地文件，并通过通知提供打开入口。

### 普通文件

普通文件不通过剪贴板 JSON 的 Base64 字段传输。用户选择、拖入或分享文件后：

1. 客户端读取文件名、MIME、大小、来源设备和时间戳；Android 会先把内容流式复制到应用缓存，以稳定文件大小。
2. 客户端向 `files-v1` 提交元数据预留，再以固定 `Content-Length` 流式发送原始二进制正文。
3. 上传端和服务器计算 SHA-256；完成文件及其索引保存在服务器本地存储。
4. 下载端流式写入目标目录，校验大小和 SHA-256 后才提交最终文件。

上传、下载和删除都由用户发起，不会因为剪贴板变化自动传输普通文件。桌面端因网络中断可能保留隐藏的续传临时文件；主动取消或完整性校验失败会删除该临时文件。Android 取消或失败时丢弃未完成目标和发送缓存。

## 服务器保存

剪贴板服务器在运行期间保存：

- 随机服务器 ID；
- 单调递增 revision；
- 最新一条文本或图片及其协议元数据。

最新剪贴板内容只存在于服务器进程内存。桌面服务器关闭后，其服务器 ID、剪贴板 revision 和内容都会重置。Android 服务器同样不持久保存剪贴板正文，但会在私有 `SharedPreferences` 中保留 revision，以避免服务重启时回退编号；服务器 ID 会重建。服务器没有剪贴板历史数据库，也不写 HTTP 访问日志。

文件服务器另外保存完成文件及索引：桌面端使用配置的“服务端文件目录”，Android 使用 `flowclip_files_v1` 私有索引和下文所列文件位置。关闭应用、停止服务或重启设备不会自动删除这些完成文件。上传预留不是完成文件，超时、失败或服务器重启时会被清理。

这不代表整条链路没有其他日志。操作系统、防火墙、Tailscale/ZeroTier、Cloudflare、FRP、反向代理或网络提供商可能记录 IP、时间、域名、请求大小或错误。使用这些组件时应检查各自的隐私政策和日志设置。

## 本地配置

桌面 `config.json` 包含：

- 随机设备 ID 和设备名；
- 服务器 URL；
- 共享密钥；
- 自动同步、轮询间隔和大小上限；
- 内置服务器监听设置；
- 文件单条上限、桌面服务端总配额、服务端文件目录和下载目录；
- 托盘、登录自启动和公网 HTTPS 校验选项。

配置位置：

| 平台 | 位置 |
| --- | --- |
| Windows | `%APPDATA%\FlowClip\config.json` |
| Linux | `${XDG_CONFIG_HOME}/FlowClip/config.json`，未设置时为 `~/.config/FlowClip/config.json` |
| macOS | `~/Library/Application Support/FlowClip/config.json` |
| Android | 应用私有 `SharedPreferences`：`flowclip_settings` |

Linux 仅使用绝对路径的 `XDG_CONFIG_HOME`；未设置或为相对路径时回退到 `~/.config`。

Linux/macOS 配置目录被设置为 `0700`、配置文件设置为 `0600`。Windows 使用用户配置目录的 ACL，Android 使用 `MODE_PRIVATE`。

共享密钥以可恢复的明文形式保存，没有放入 Windows Credential Manager、macOS Keychain、Linux Secret Service 或 Android Keystore。它可以阻止不知道密钥的网络请求，但不能抵御已经控制用户会话、读取应用配置或取得设备权限的攻击者。Android Manifest 设置了 `allowBackup=false`、`fullBackupContent=false`，并通过 `data_extraction_rules.xml` 排除云备份和设备迁移中的应用私有数据；这仍不能替代设备锁和系统更新。

从旧桌面版本升级时，FlowClip 会读取旧的 `~/.flowclip/config.json` 并把内容写入当前平台的规范目录。迁移不会删除旧文件；确认新配置生效后，应手动删除旧副本。无法解析的配置还可能在同一目录中改名为 `config.invalid.json`，删除数据时应检查整个 FlowClip 配置目录。

## 图片和普通文件保存

- Android 10 及以上：收到的图片写入 MediaStore 的公共 `Pictures/FlowClip`，其他具有相应媒体访问能力的应用和用户可以看到；卸载 FlowClip 不会自动删除这些公共图片。
- Android 8/9：图片写入应用专属外部图片目录的 `FlowClip` 子目录，卸载应用时由系统删除。
- Windows、Linux 和 macOS：收到的图片写入系统剪贴板，FlowClip 自身不另外保存图片文件。其他应用或剪贴板管理器可能自行留存。

图片文件名来自经过清理的协议文件名；缺少可用扩展名时会按 MIME 类型和当前时间生成。

普通文件使用不同位置：

- 桌面服务器：默认 `~/Downloads/FlowClip Server`，包含 `index.json`、完成文件 blob 和服务器锁；可以设置为其他绝对路径。
- 桌面客户端下载：默认 `~/Downloads/FlowClip`；同名文件不会被覆盖，而是生成带编号的新名称。网络中断时可能出现隐藏 `.flowclip-<id>.part` 和 `.flowclip-locks`。
- Android 10 及以上：服务器接收和客户端下载的普通文件均写入 MediaStore 公共 `Download/FlowClip`，卸载 FlowClip 不会自动删除。
- Android 8/9：普通文件写入应用专属外部下载目录的 `FlowClip` 子目录，卸载应用时由系统删除。

从服务器文件列表执行“删除”会删除服务器设备上的对应完成文件，不会删除其他客户端已经下载的副本。

## Android 权限

Android Manifest 声明：

| 权限 | 用途 |
| --- | --- |
| `INTERNET` | 连接用户指定的 FlowClip 服务器，或在手机上接受内置服务器连接 |
| `ACCESS_NETWORK_STATE` / `CHANGE_NETWORK_STATE` | 观察网络恢复并满足前台服务类型要求 |
| `POST_NOTIFICATIONS` | 显示常驻同步状态和收到内容的通知 |
| `RECEIVE_BOOT_COMPLETED` | 自动接收启用时在开机后尝试恢复 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_CONNECTED_DEVICE` | 持续轮询用户设备服务器或维持手机内置服务器 |

应用不申请联系人、位置、相机、麦克风或通用文件读取权限。发送普通文件通过用户授权的系统文件、拖放或分享 `content://` URI 读取；FlowClip 在临时授权有效时打开只读文件描述符，并在该批次结束、失败或取消后关闭，不接受自身私有 Provider URI 作为外部分享来源。Android 10+ 通过 MediaStore 保存收到的图片和文件，Android 8/9 使用应用专属目录。

## 网络保密性

共享密钥通过 `Authorization: Bearer` 请求头发送。HTTP 下它、剪贴板内容、文件元数据和文件正文都可能被同一网络中的观察者读取或修改。

- 桌面端默认拒绝公网 IP 和所有域名的 HTTP，但允许受信范围内的字面 IP。
- Android 默认还要求用户明确开启“允许可信局域网 HTTP 明文连接”。
- 两端都可以关闭公网 HTTPS 校验，但该开关不会增加任何加密。
- HTTPS 使用系统证书信任库；FlowClip 不实现证书固定。

公网应使用有效 HTTPS 或加密 VPN。共享密钥不是 TLS 的替代品，也不是端到端密钥：HTTPS 隧道或反向代理终止 TLS 后，能够接触明文内容。

## 数据大小和资源限制

剪贴板内容：桌面端默认单条上限 20 MB，可配置 1 至 100 MB；Android 默认及最高 8 MB。桌面端图片解码还限制到 3200 万像素，桌面剪贴板后端有 100 MB 的安全读取上限。

普通文件：桌面默认单文件上限 2048 MB，可配置 1 至 10240 MB；桌面服务器总配额默认 8192 MB、最高 51200 MB，最多 100 条记录。Android 默认单文件上限 256 MB、最高 2048 MB；手机服务器最多 50 个完成与待上传记录，其中待上传预留最多 8 个。它没有独立总配额设置，仍受设备剩余空间限制。

剪贴板协议中的 Base64 会让网络 JSON 比原始数据约大三分之一；普通文件正文不使用 Base64。服务器限制并发请求、读取超时和请求体大小，但它仍是面向个人设备的轻量服务，不应作为公共匿名上传服务。

## 删除和重置

### 桌面

1. 先在设置中关闭“登录系统时启动”，让 FlowClip 移除对应自启动入口。
2. 退出应用。
3. 删除本平台的 FlowClip 配置目录，并检查旧版 `~/.flowclip` 是否仍有迁移前副本。
4. 按需删除默认或自定义的 `FlowClip Server` 与 `FlowClip` 文件目录。
5. 如不再使用，删除应用或 Release 解压目录。

删除配置会移除共享密钥、设备 ID 和设置。系统剪贴板及第三方剪贴板管理器中的副本不由 FlowClip 控制。

### Android

- 在系统应用设置中清除 FlowClip 存储，或卸载应用，以删除私有配置和 Android 8/9 的应用专属图片。
- Android 10+ 的 `Pictures/FlowClip` 是公共媒体目录，需要在相册或文件管理器中单独删除。
- Android 10+ 的公共 `Download/FlowClip` 文件也需要在下载管理器或文件管理器中单独删除。
- 停止后台服务不会删除配置或已保存图片。

### 服务器

退出桌面 FlowClip 或停止 Android 前台服务，即可清除服务器内存中的最新剪贴板内容；这不会删除 `files-v1` 完成文件。请在文件列表逐项删除，或在停止服务器后清理对应存储目录。隧道、反向代理和虚拟网络日志需要在对应产品中单独处理。

## 共享设备与泄露处理

- 不要在多人共用账号中开启自动同步，除非所有使用者都理解剪贴板会被发送。
- 不要把共享密钥、服务器公网地址或含敏感内容的截图提交到公开 Issue。
- 设备丢失、配置被复制或密钥疑似泄露时，在所有设备生成并更换同一个新密钥。
- 更换密钥后，旧客户端会立即认证失败。
- Android 10+ 已保存的图片和第三方剪贴板管理器历史需要单独检查。
- 服务器和所有客户端已经保存的普通文件副本需要逐台设备检查。

安全漏洞请按仓库根目录的 [安全政策](../SECURITY.md) 使用 GitHub Private Vulnerability Reporting，不要公开披露。
